# PocketStore

## Descripción

PocketStore es una aplicación web de una sola página (SPA) desarrollada con Vanilla JavaScript.

La aplicación consume información desde una API pública para simular un catálogo de productos y utiliza tecnologías PWA para permitir el almacenamiento en caché y funcionamiento sin conexión.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- Service Workers
- Cache Storage API
- Web App Manifest
- JSONPlaceholder
